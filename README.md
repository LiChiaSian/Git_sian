# YOLO 實時鏡頭 / 本機圖片辨識與手動匡列控制介面(AI協助)

本專案是一個基於 **PyTkinter** 圖形介面開發的實時物件偵測與手動標註工具。除了支援網路攝影機串流實時偵測外，亦提供本機圖片檢視、圖像縮放平移、右鍵自訂劃框、標註物件多重排序與刪除，以及匯出圖像與文字數據等功能。

---

## ✨ 核心功能

1.多來源辨識輸入：
    實時攝影機串流: 自動掃描電腦可用鏡頭，支援實時畫面拉取與背景多線程 YOLO 物件偵測。
    本機圖片檢視: 支援載入 JPG、PNG、BMP、WEBP 等格式圖片進行單張辨識。
2.YOLO 參數與類別動態調控：
    即時調整 Confidence與IoU門檻。
    可切換推論影像尺寸 (`imgsz`: 320, 640, 1280) 與運算設備 (`cpu` 或 `GPU 0`)[cite: 4]。
    支援勾選特定類別（人、汽車、寶特瓶、手機等）或開啟全類別偵測。
3.互動式畫布操作：
    滑鼠滾輪：縮放（Zoom in / out）。
    滑鼠左鍵拖曳：平移（Pan）檢視畫面。
    滑鼠右鍵拖曳：手動匡列自訂標註區域（標記為 手動區域）。
4.標註物件清單與多元管理：
    焦點高亮：點擊右側列表項目，畫面上對應物件會高亮顯示並聚焦。
    多重排序：依「名稱」、「信心度 (高/低)」、「面積大小 (大/小)」或「預設序號」重新排列。
    靈活刪除：刪除單一選取項目、僅清除自訂框，或一鍵清空所有標註框。
5.資料快照與匯出：
    實時快照：一鍵快速保存當前原圖與帶有繪製框的影像[cite: 4]。
    完整數據匯出：匯出至 `captures/` 資料夾。
